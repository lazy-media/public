# Joining Lazy Media's Server

## Want to Join Lazy Media's Server?

This page explains how to request access.

It also covers the recommended login method.

### Policies first

Read these before you request access:

* [Privacy Policy](privacy-policy.md)
* [Terms of Service](terms-of-service.md)

### Recommended login method (best experience)

Use the **Lazy Media – Authentik** portal when available.

When redirected to Authentik, choose **PLEX OAUTH**.

That gives the best compatibility across services.

{% hint style="info" %}
Discord login is supported, but it has a more limited feature set.
{% endhint %}

### Access policies (quick summary)

* Plex access is restricted to approved users.
* Public email-based registration is currently unavailable.

### Alternative login: Discord

Discord authentication is available with these requirements:

* You must be a member of the [Lazy Media Discord Community](https://link.lazymedia.media/lazymedia-discord-promo-page).
* Discord login does **not** provide Media Server access.

#### What the Discord community includes

* Support channels for:
  * Lazy Media apps
  * Authentik configuration
  * Ubiquiti / UniFi support
  * Homelab apps
* Plex-related features:
  * New content notifications
  * Monthly newsletters
  * Media issue reporting
  * Content request system

{% hint style="info" %}
Automated role assignment is being implemented. Until then, you may need to manually select roles.
{% endhint %}

### Account consistency (important)

If you are **not** using Plex OAuth or Discord auth, be consistent.

Your **email address and username should match exactly** across integrated services.

Credential mismatches can cause login issues across `lazymedia.media` apps.

#### Best practices

* Prefer Plex OAuth (recommended) or Discord authentication when possible.
* Avoid changing usernames or emails after account creation.
