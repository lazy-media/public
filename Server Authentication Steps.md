# How to Login to Lazy Media's Server

## PLEASE BE AWARE THAT WITH GAINING ACCESS TO THIS SERVER, YOU WILL BE REQUIRED TO MAKE A MONTHLY PAYMENT TO CONTINUE ACCESS. THIS PAYMENT IS TO HELP WITH SERVER MAINTENANCE.

## Main Login Method (Recommended)
### Please note that most accounts / requests are restricted to Family or Friends only.
### Due to how the server is currently setup, a Plex Account is required as that is the main authentication method currently setup. In order to have access using your Plex account, I must have you in my Plex Friends List.

- Create a free Plex account
- Create a free Google Account (if needed)
- Fill out the Form located [Here](https://sites.google.com/view/b-repairs/plex/plex-requests)
- Wait for an email confirmation stating you have access.
- Read the email for instructions on how to finish setup.


## Alternate Login Method (Not Recommended)
### Please note that this method would be for anyone who doesn't want to create a Plex account.
- Email admin for a request to have an account.
- Write a lengthy reason on why you would like access to my server, along with the list of apps you would like access to.
