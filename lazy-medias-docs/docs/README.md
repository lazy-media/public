# Lazy Media's Docs

Lazy Media documents the self-hosted services, configurations, and fixes used in its home lab.

The guides are practical references. They cover deployments, integrations, and common troubleshooting steps.

### Overview

This documentation is a growing collection of everything Lazy Media has documented across real-world home-lab deployments. It is intended as a practical quick-reference for common tasks, fixes, and configuration patterns that new and everyday home-labbers run into. It includes troubleshooting, installation guides, and extra configuration steps that may be missing, unclear, or not covered in official documentation.
