# Reactive Resume

This is an older version of what the original maintainer currently has published. If you would like to use the new version by Amruth Pillai, please visit [https://rxresu.me](https://rxresu.me/)

{% hint style="info" %}
_Lazy Media is currently working on a forked version of this new version as well, just waiting until the original maintainer is done fixing issues and adding features._
{% endhint %}

{% hint style="danger" %}
Reactive Resume is currently down. Lazy Media believes this is due to an Oracle Cloud issue.

Oracle Cloud recently downgraded its Free Tier limits from 4 CPU / 24 GB RAM down to 2 CPU / 12 GB RAM, without notifying Lazy Media of this change. Based on the timing — the instance went offline roughly halfway through the month — Lazy Media believes the Reactive Resume instance hit its new, reduced monthly resource limit under the Free Tier.

Please be patient while this gets resolved. In the meantime, please use the original maintainers version.
{% endhint %}
